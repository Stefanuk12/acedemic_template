# Tables, equations and code

## Tables (CSV-driven)

The csv filter (`filters/csv.lua`) lets you embed CSV directly in
markdown — the parsed table is rendered with pandoc-crossref's caption
syntax so it appears in the List of Tables and is cross-referenceable
as `[@tbl:label]`.

Inline CSV:

```{.csv #tbl:inline-sales caption="Quarterly revenue by region (inline CSV)"}
Region,Q1,Q2,Q3,Q4
North,124,138,152,167
South,98,112,131,148
East,156,165,178,194
West,87,95,108,122
```

Loaded from a file with `file=`:

```{.csv #tbl:file-sales caption="Same data, loaded from data/example-data.csv" file=data/example-data.csv}
```

The data shown in [@tbl:inline-sales] and [@tbl:file-sales] is identical;
the second example demonstrates referencing an external CSV which is
useful when the dataset is large, kept under version control, or
generated by a separate pipeline.

The CSV reader handles double-quoted fields and `""` escapes — useful
when a cell contains the delimiter or a literal quote character:

```{.csv #tbl:csv-quoting caption="CSV reader: quoted fields, embedded commas, doubled-quote escapes"}
Item,Description,Note
A,"Comma, inside",plain
B,"Quote ""inside""",plain
C,plain,"Comma, and ""quote"" together"
```

The parser exercised by [@tbl:csv-quoting] is the same one used for the
sales tables above; this block is what stops a CSV regression from
slipping past CI.

## Equations

Inline math is `$E = mc^2$`. Display math gets its own line; with a
`{#eq:label}` it becomes cross-referenceable:

$$ E = mc^2 $$ {#eq:einstein}

$$ \nabla \cdot \mathbf{E} = \frac{\rho}{\varepsilon_0} $$ {#eq:gauss}

The famous result in [@eq:einstein] expresses mass-energy equivalence;
[@eq:gauss] is one of Maxwell's equations relating electric flux to
charge density.

## Code listings

Fenced code blocks render with syntax highlighting. Adding the
`.numberLines` class adds line numbers; a `caption=` attribute plus
`#lst:label` identifier makes them cross-referenceable as
`[@lst:label]`:

```{.python .numberLines #lst:fib caption="Recursive Fibonacci with memoisation"}
from functools import lru_cache

@lru_cache(maxsize=None)
def fib(n: int) -> int:
    if n < 2:
        return n
    return fib(n - 1) + fib(n - 2)

print([fib(i) for i in range(10)])
```

The implementation in [@lst:fib] uses `functools.lru_cache` to memoise
intermediate results, reducing the time complexity from exponential to
linear in the input size.
