# Example diagrams (D2)

[D2](https://d2lang.com) is a modern declarative diagram language. The
fence pattern matches the other backends — `caption=` populates the
List of Figures, the `#fig:label` provides a cross-reference target.

```{.d2 #fig:d2-system caption="D2 system architecture (example)"}
direction: right

User: {
  shape: person
}

WebApp: {
  shape: rectangle
  label: "Web App"
}

API: {
  shape: hexagon
}

DB: {
  shape: cylinder
  label: "Database"
}

User -> WebApp: HTTPS
WebApp -> API: REST
API -> DB: SQL
```

```{.d2 #fig:d2-sequence caption="D2 sequence diagram (example)"}
shape: sequence_diagram

User -> WebApp: Submit form
WebApp -> API: POST /resource
API -> DB: INSERT
DB -> API: OK
API -> WebApp: 201 Created
WebApp -> User: Success
```
